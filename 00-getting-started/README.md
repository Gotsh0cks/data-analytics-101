# Module 0: Getting Started

## Welcome! Start Here.

You are about to learn data analytics from scratch. No experience required. Seriously — if you have never written a line of code, never opened a terminal, and are not entirely sure what a "file extension" is, you are in exactly the right place.

Learning something brand-new can feel confusing at first. That is completely normal. Every data analyst, every programmer, every tech professional started exactly where you are now. The confusion does not mean you are doing it wrong — it means you are learning.

Take your time. Follow the steps in order. If something does not work on the first try, check the troubleshooting guide at the end of this module. You have got this.

---

## What You Will Set Up in This Module

By the end of Module 0, your computer will have everything you need to start analyzing data. Here is what we will install, in order:

| Step | What You Will Do | Guide |
|------|-----------------|-------|
| 1 | Learn what data analytics actually is | [what_is_data_analytics.md](what_is_data_analytics.md) |
| 2 | Install Python (the programming language we will use) | [install_python.md](install_python.md) |
| 3 | Install VS Code (the app where you will write code) | [install_vscode.md](install_vscode.md) |
| 4 | Run your very first program | [running_your_first_script.md](running_your_first_script.md) |
| 5 | Install SQL Server and Azure Data Studio (for working with databases) | [install_sql_server.md](install_sql_server.md) |
| 6 | Bookmark the troubleshooting guide for later | [common_errors.md](common_errors.md) |

**Please follow the guides in the order listed above.** Later steps depend on earlier ones. For example, you need Python installed before you can run your first program.

---

## How Long Will This Take?

Plan for about 1 to 2 hours. Most of that time is waiting for things to download and install. You will not be staring at the screen the whole time — feel free to grab a coffee while installers run.

---

## If You Get Stuck

- Check [common_errors.md](common_errors.md) — it covers the most frequent problems beginners run into.
- Copy the exact error message and paste it into Google. Someone else has almost certainly had the same problem.
- Take a break. Sometimes walking away for 10 minutes and coming back with fresh eyes is all you need.
