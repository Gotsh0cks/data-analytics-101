# Installing Tableau Public

## What is Tableau Public?

Tableau Public is the **free version** of Tableau. It has the same powerful visualization features as the paid version, with one key difference: all work you save is published publicly to the Tableau Public website. This is actually a benefit for learners — it builds your portfolio automatically.

## Step-by-Step Installation

### Step 1: Go to the Download Page

Open your web browser and go to:

**public.tableau.com/en-us/s/download**

### Step 2: Enter Your Email

Tableau asks for your email address to create a free account. Enter your email and click **Download the App**.

### Step 3: Run the Installer

1. Open the downloaded file (usually called `TableauPublic.exe`)
2. If Windows asks "Do you want to allow this app to make changes?", click **Yes**
3. The installer will run automatically — no options to configure
4. Wait for the installation to finish (this takes a few minutes)

### Step 4: Launch Tableau Public

Once installation is complete, Tableau Public opens automatically. You'll see the **Start** page with options to connect to data.

If it doesn't open automatically, find "Tableau Public" in your Start menu.

### Step 5: Create Your Tableau Public Account

The first time you save work, Tableau will ask you to sign in:

1. Click **Create one for free** if you don't have an account
2. Fill in your name, email, and password
3. Verify your email address
4. Sign in to Tableau Public

## System Requirements

- Windows 10 or 11 (64-bit)
- At least 2 GB RAM (4 GB recommended)
- About 1.5 GB of free disk space
- Internet connection (required for saving/publishing)

## Tableau Public vs. Tableau Desktop

| Feature | Tableau Public (Free) | Tableau Desktop (Paid) |
|---------|----------------------|----------------------|
| Create charts & dashboards | Yes | Yes |
| Connect to CSV, Excel | Yes | Yes |
| Connect to databases | Limited | Full |
| Save locally | No (saves to web) | Yes |
| Work is public | Yes | No |
| Cost | Free | ~$70/month |

For learning, Tableau Public has everything you need.

## Troubleshooting

**"Tableau Public has stopped working"**
- Make sure your Windows is updated
- Try right-clicking the app and selecting "Run as administrator"

**Can't find Tableau in Start menu**
- Search for "Tableau" in the Windows search bar
- If it's not there, try reinstalling

**Slow performance**
- Close other applications to free up memory
- Work with smaller datasets while learning (our datasets are small enough)
