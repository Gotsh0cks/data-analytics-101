# Module 0: What Is Data Analytics?

## What This Module Covers

Before you install a single tool or write a single line of code, this module answers the fundamental questions: What *is* data analytics? Why does it matter? What tools do professionals use? And what kind of career can it lead to?

## Lessons

| Lesson | Topic |
|--------|-------|
| 1 | [What Is Data Analytics?](01_what_is_data_analytics.md) — Concepts, the analytics workflow, and why it matters |
| 2 | [Common Tools Overview](02_common_tools_overview.md) — Excel, Python, SQL, and Tableau — what each does and when to use it |
| 3 | [Careers and Skills](03_careers_and_skills.md) — Job roles, salaries, skills in demand, and how this course prepares you |

## Time Estimate

About 30-45 minutes of reading. No installation or coding required.

## Before You Move On

You are ready for Module 1 when you can:

- Explain data analytics in one or two plain-English sentences.
- Name the basic workflow: ask, collect, clean, analyze, share.
- Recognize why spreadsheets, Python, SQL, and Tableau each matter.
- Name one type of question a data analyst might answer.
- Describe one data-related role that sounds interesting or useful.

## Quick Reflection

- What part of data analytics sounds most familiar from everyday life?
- Which tool sounds most intimidating right now?
- What is one question you wish you could answer with data?
