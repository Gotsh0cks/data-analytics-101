# Module 2: Basic Visualization

In this module, you'll learn how to create charts and graphs from your data. A good chart can tell a story that a table of numbers never could. We'll use two Python libraries: **matplotlib** (the foundation) and **seaborn** (which makes prettier charts with less code).

## What You'll Learn

By the end of this module, you will be able to:

- Create bar charts to compare categories
- Build line charts to show trends over time
- Make pie charts and scatter plots to explore your data
- Style and polish your charts so they look professional

## A Quick Note Before You Start

Charts are one of the most powerful tools in data analytics. When you hand someone a table with 100 rows of numbers, their eyes glaze over. When you hand them a clean bar chart, they immediately see the story. This module teaches you how to tell that story.

Each lesson includes a Python script you can run to generate charts. The scripts will both display the chart on your screen and save it as an image file. Try tweaking the code -- change colors, labels, and data -- to see what happens!
