# First 30 Minutes

This guide is for your first sitting with the course. You do not need to finish setup today. The goal is to open the course, understand the path, and complete one small step.

## What You Need

- A Windows computer.
- The `data-analytics-101` course folder.
- A little patience for unfamiliar tools.
- Optional: VS Code, if you already installed it.

If you only have the files open in Windows Explorer, that is enough to start.

## Minute 0 To 5: Open The Course Folder

1. Find the `data-analytics-101` folder.
2. If it is still a ZIP file, right-click it and choose **Extract All** first.
3. Open the extracted folder.
4. Look for these files:
   - `START_HERE.md`
   - `README.md`
   - `progress_tracker.md`
   - `GET_HELP.md`

You are in the right place if you can see numbered folders like `00-what-is-data-analytics` and `01-setting-up`.

## Minute 5 To 10: Open The Tracker

Open `progress_tracker.md`.

This is your checklist. You can edit it later and change `[ ]` to `[x]` when you finish something.

Do not worry about the full list yet. It is supposed to be longer than what you can finish in one sitting.

## Minute 10 To 20: Read The Course Map

Open `START_HERE.md` and read:

1. **What This Course Teaches**
2. **The Best Path Through The Course**
3. **How To Use Exercise Support**

The course is designed to move in this order:

1. What data analytics is.
2. Setup.
3. Spreadsheets.
4. Python.
5. SQL.
6. Charts and dashboards.
7. Real-world datasets.
8. Capstone project.

You do not need to understand all of that today. You only need to know where the path starts.

## Minute 20 To 30: Start Module 0

Open `00-what-is-data-analytics/README.md`.

Read the module overview, then open `01_what_is_data_analytics.md`.

Your first win is simple: explain in your own words what data analytics is and why someone might use it.

## If You Already Installed Python

If Python is already installed, you can check your setup from the main course folder:

```bash
python check_setup.py
```

If you see mostly `[OK]`, great. Keep going.

If you see `[FIX]`, do not panic. Open `GET_HELP.md` and look for the error or use the help request template.

If `python check_setup.py` does not run yet, skip it for now and continue with Module 0. Setup happens in Module 1.

## A Good First Session

A good first session can be as small as:

- You opened the course folder.
- You found the progress tracker.
- You read `START_HERE.md`.
- You started Module 0.
- You know where `GET_HELP.md` is.

That counts.

## Where To Stop

Stop when one of these is true:

- You finished Module 0.
- You installed one setup tool and need a break.
- You hit an error and filled out the help template.
- You feel mentally full.

This course works better when you come back fresh than when you push through frustration.
