# Module 6: Tableau Public

## What This Module Covers

Tableau is one of the most widely used data visualization tools in the industry. Many job postings for data analysts list Tableau as a required or preferred skill. In this module, you'll learn to use **Tableau Public** — the free version — to create interactive dashboards and publish them online.

By the end of this module, you'll be able to:

- Connect Tableau to CSV files and databases
- Build charts and graphs with drag-and-drop
- Format and style visualizations professionally
- Combine multiple charts into interactive dashboards
- Publish your work to Tableau Public for your portfolio

## Why Tableau?

You've already learned to create charts with matplotlib in Python. So why learn Tableau?

1. **Speed.** Tableau lets you create charts in seconds by dragging and dropping — no code needed.
2. **Interactivity.** Tableau dashboards are interactive — users can click, filter, and explore.
3. **Industry standard.** Many companies use Tableau for reporting and business intelligence.
4. **Portfolio.** Published Tableau dashboards are visible to potential employers.

**Tableau doesn't replace Python** — they complement each other. Use Python for data cleaning and complex analysis. Use Tableau for presenting results to stakeholders.
