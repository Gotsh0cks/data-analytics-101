# Module 1: Excel Analysis with pandas

In this module, you'll learn how to work with spreadsheet-like data using Python and a library called **pandas**. Think of pandas as a super-powered Excel that you control by typing commands instead of clicking.

## What You'll Learn

By the end of this module, you will be able to:

- Load data from CSV files (the most common spreadsheet format) into Python
- Look at and explore your data to understand what you're working with
- Filter and sort data to find exactly what you need
- Summarize data with totals, averages, and grouped calculations
- Clean up messy data by handling missing values, duplicates, and incorrect types
