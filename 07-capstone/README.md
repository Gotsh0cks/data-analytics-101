# Module 7: Capstone Project

## What This Module Is

This is not a lesson it is a project. You will use **every skill** you have learned in this course to complete an end-to-end data analysis, from raw data to published dashboard.

This is the kind of work you would do on the job, and the result will be a portfolio piece you can show to potential employers.

## What You Will Do

1. **Choose a dataset** from Module 6 (or find your own)
2. **Explore and clean** the data with Excel and/or pandas
3. **Query** the data using SQL
4. **Visualize** your findings with matplotlib
5. **Build a dashboard** in Tableau Public
6. **Publish** your dashboard and summarize your findings

## Before You Start

Make sure you have completed all previous modules. You will need:

- Python with pandas, matplotlib, seaborn installed
- SQL Server running with the practice database
- Tableau Public installed
- External datasets downloaded (from Module 6)

## Project Guide

Follow the step-by-step instructions in [Project Guide](01_project_guide.md) for a structured walkthrough.

If you prefer to work independently, use [project_template.py](03_project_template.py) as a starter script and [Example Questions](02_example_questions.md) for inspiration on what questions to answer.

## Deliverables

By the end of this project, you should have:

1. A Python script that loads, cleans, and analyzes the data
2. At least 3 matplotlib charts saved as PNG files
3. A Tableau dashboard published to your Tableau Public profile
4. A brief write-up (even just a few sentences) explaining what you found

## Time Estimate

Plan for 3-5 hours, depending on how deep you go. There is no "right" answer the goal is to practice the full workflow.

## You Made It!

If you have completed all modules and finished your capstone project congratulations. You now have hands-on experience with Excel, Python, SQL, matplotlib, and Tableau. That is a strong foundation for an entry-level data analyst role. Keep practicing, keep exploring new datasets, and keep building your portfolio.
